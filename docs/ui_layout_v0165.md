# 界面布局规范（v0.16.5）

窗口截图在 `docs/art/v0165/`。改前是 v0.16.4 的同一套调试场景；改后是本版。青庐、静室、地图的改前图里常被一条没关的江湖事件挡住（调试命令的老问题），对照时以坊市、人物、行囊、创建页为准。没有在真机上看过。

同类手机修仙 / 人生模拟（觅长生、一念逍遥、鬼谷八荒手游、修仙家族模拟器）的共同结构是：顶上一条紧凑状态，中间以图和格子为主，底下固定导航，话用短提示，详情用底部抽屉，长文只进日志。本版按这个收，不再一页一种排法。

## 骨架

1. **顶栏**一直在。年月、境界和一条细进度、寿元、辟谷丹、灵石、行囊。高度大约一行半，不在下面再挂常驻句子。
2. **主区**是场景或格子。青庐、地图是整幅画上的热点。坊市是题头图、操作格、地点图牌、人脸格。人脸两列，点卡片本身，卡片下不再挂第二颗按钮。
3. **底栏**是页签：青庐、历练、行囊、江湖、生平。游历时底栏换成「回青庐」「去别处」。
4. **短提示**浮在顶栏下，大约三秒后淡出，点一下就收。存档冲突这种错误一直留着。句子进 `s["notes"]`（近况），生平页和游历「行记」抽屉都能回看，不写进青庐行记，免得和履历搅在一起。一次来好几条，顶上只留最新一句，并写明还有几条。
5. **详情**用底部抽屉：铺子、差事、拍卖、手记、闭关须知、这一路的行记。抽屉按内容收高，不撑满屏。底边停在底栏之上，页签一直露着、点得着。点抽屉外的遮罩，或点标题旁的「收起」，抽屉就关。「收起」留在屏内，不跟长说明一起挤出右缘。手记这一张，点遮罩或「收起」和「记下了」一样，这一张不再弹出。买下器物后回到铺子，可以接着挑；抽屉里写明已经收进行囊，「回铺子」和「收起」都在。
6. **长文**只在履历、行记、对话结果里。静室上的说明收进「闭关须知」。手记不再压在院子顶上。

## 字号和按钮

- 页标题 18，区块 16，正文 13–14，注释 11–12。标题屏的「青庐远行」仍是大字。
- 能点的控件最短边 44。格子里的按钮不再混用 34、46、52、56、60。
- 左右边距 6，块与块之间 4。

## 坊市 / 地点

- 题头只写地名和游了几个月。回青庐在底栏，不在题头再写一遍。右边是「行记」。
- 买辟谷丹、差事榜、器物铺、药铺仍是首屏文字按钮。茶肆、拍卖行、巷尾仍是图牌。
- 这一带的人不再写一行标题，也不再每人一颗「上前」。点人脸打开同一个人的详情；人就在这里、这个月还没上前、眼前没有别的事时，详情顶上就是问问修行、打听风声、换丹 / 讨教 / 结伴 / 问去路、点个头走开。消耗和结果仍走原来的相逢。人不在这一带（江湖档案）就只有详情。
- 390×844 和 360×640 的首屏都要同时看见买卖、差事、图牌和至少四张整脸。内容高出屏幕时仍能滑到底；手指在卡片上滑过一小段算翻页，轻点才打开。

## 审核里看到的问题，以及这次怎么处理

| 问题 | 处理 |
| --- | --- |
| 顶栏下常驻「这个月在巷尾转悠……」 | 改成可点掉的短提示，句子进近况 / 行记 |
| 人脸下面再挂「上前」，点卡片却只看档案 | 去掉「上前」。点人同时能看详情和交互 |
| 题头重复「回青庐 N 个月」，又有「这一带的人」 | 题头只留地名和游历月数；人多时不再加标题 |
| 360 首屏第二排脸被「上前」和底栏切掉 | 拿掉「上前」、收矮题头和图牌后，五张整脸和底栏同屏 |
| 按钮高度从 34 到 60 混用 | 可点控件统一到 44（标题屏主按钮 48） |
| 静室、创建、人物页用大段说明占首屏 | 说明进抽屉或页签；首屏留操作和脸 |
| 旧主手记是一块压在院子上的段落 | 改成底部抽屉，院子还在 |
| 人物页顶上喜、志、记得占掉交互的位置 | 收到「心事」页签；能上前时交互在详情顶上 |
| 地图底下一整行教程 | 收成「认得 N 处」。怎么走，手记里已经写了 |
