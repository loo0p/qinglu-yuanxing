# 界面视觉（v0.16.7）

布局骨架仍是 `docs/ui_layout_v0165.md`（顶栏、底栏、抽屉、短提示）。这一版只改按钮的轻重和图的层次。窗口截图在 `docs/art/v0167/`。没有在真机上看过。

同类修仙手游（觅长生、一念逍遥、鬼谷八荒）的共同做法是：主操作又大又醒目，次操作带图标，离开和收起用文字；人物页是一幅地方的画，人站在画里，名字用牌子压上去。本版按这个分，不再一页全是同样大小的纸色方钮。

## 按钮三级

按按钮文字自动分档（`main.gd` 的 `_btn_rank`）。字不变，测试仍按原文点。

1. **主操作。** 朱砂底，字和图标都是米白（对比不低于 4.5:1），比别的高一截，右上角一点浅金在轻轻闪。按下缩到 0.94 并换成更深的朱砂。用在：问问修行、买辟谷丹、差事榜、出发、新游戏、冲关、静室里的「一年」。
2. **次操作。** 木牌：暖纸色、深褐边、底边加厚，像一块薄木片。能对上的动作带小图标（打听风声、讨教、换丹、结伴、问去路、器物铺、药铺、去别处、回青庐）。按下变暗、缩一下。
3. **弱操作。** 没有框，只有一行淡字。用在：点个头走开、收起、返回、回去、算了、不必再提、回标题、回铺子、闭关须知、题头上的行记。点按区域仍在，只是看起来轻。
4. **返回。** 「回江湖」「回坊市」是清楚的纸色按钮，左侧一个返回箭头，字是深墨，不像灰掉的禁用态。

底栏垫一层实纸。每个页签图标在上（22px）、两个字在下，未选中也是深墨，不和字叠在一起。选中的底下一条朱砂。人物页的生平 / 关系 / 心事 / 记得她同样是图标页签，未选中也是深墨。

坊市、江湖的人脸是三列，纸色淡金框，名字下面的关系一行完整露出来。

## 小图标

`scripts/ink_glyph.gd` 在游戏里画 32×32 的透明小图，显示成 22–24px，笔画加粗、实心，不另借图标包。主钮上的图标是米白，木牌和底栏上是深墨。问修行是书卷，打听风声是茶盏，讨教是剑，换丹是丹瓶，结伴是两个人，问去路是石径，闭关 / 一年是门，行囊是口袋，器物铺是铺面，药铺是草，历练是山，返回是箭头。行囊格子、器物槽仍用原来的器物图。

## 画面

- **人物详情：** 顶上一条这个人所在地方的图（竖幅取上半，地标还在）。立绘站在画的下沿，高度大约是这条图的七成，不到半屏。名字、门派、境界、关系写在叠上去的纸牌上，角上有一枚朱印。
- **江湖、行囊、生平：** 页首一条地方或院子的图，标题用小纸牌压在画上。后面的格子仍是纸卡片。
- **器物铺、药铺、差事榜、拍卖、静室须知：** 抽屉顶上一条对应的图，下面才是货和说明。门下靠每一行的头像，不再在顶上加一条图，免得把「指点」挤出小屏。
- **坊市：** 买卖和差事是主操作（朱砂），铺子是木牌，茶肆那些仍是图牌。

按下都有缩放。主操作可用时右上角一点浅金会呼吸一下。短提示按屏宽量高度，最多两行，停在顶栏下面，不盖住底栏。
