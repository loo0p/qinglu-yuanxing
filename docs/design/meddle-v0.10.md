# 插手（v0.10）

用户要的：玩家能对 NPC 正在做的事出手。通过传闻或看出某人的心思，她可以去提醒当事人、去帮、去掺一脚、去说和、抢先下手、去宗门告一状，或者不管。插手要花时间、灵石、冒险，结算走人物自主那一套；结果写回所有当事人的记忆、看法、动机。

## 机制（scripts/meddle.gd）
- **谋事**：人物自主挑出的 8 种动作（寻仇、截杀、偷窃、夺宝、造谣、示好、叛门、讨债）中，一部分不当场了结，要过 3–6 日才动手（她认识其中一方时 60%，否则 22%；同时最多 6 件，一人一件）。状态在 `world.w["plots"]`（整数 / 字符串，JSON 往返不变）。
- **走漏**：起念时有 80%（认识）/ 40%（不认识）的机会变成一条坊市传闻（种类“谋”，按起念人的性子挑说法）；她认识其中的人时 70%（不认识时 25%）会有人来报信，或她在路上听见——事件“风声”，走原来人物自主找上门的队列，所以不改节奏。
- **从传闻 / 心事插手**：江湖页里还没到日子的“听说某某要……”带一个“插手”按钮；人物卡心事页里，她知道的事下面有“插手这件事”。这是玩家自己点的，不计入说书人的节奏。
- **选项**（每件事 ≤5 个，最后一个都是“不插手”）：
  - 寻仇 / 截杀：递话、赶去身边护着（耽搁 2 日，要打一场）、说和（寻仇；有钱就备礼）/ 告到宗门（截杀）、帮起念的人一把（与目标亲近时不给这个选项）。
  - 偷窃：提醒、守在暗处拿人（耽搁 1 日）、告状。夺宝：抢先去取（耽搁 1 日）、递话、劝两边对半、帮着抢。造谣：提醒、当众驳回、跟着添两句。
  - 示好：替他说好话、提醒对方当心。叛门：去劝、替他引开巡山的人（耽搁 1 日，35% 被认出）、去宗门报信。讨债：替欠债的人还上、劝宽限。
  - 起念的是她的熟人、事又是坏事：头一个选项是“去拦着”。
- **结算**：打斗走 `W._roll`；帮人 / 到期了结走 `AG.npc_resolve`，`_win` 读 `w["edge"]` 给受了提醒的一方或她帮的一方加成。提醒过的偷窃、造谣直接落空；提醒过的寻仇、截杀、夺宝 45% 躲开，否则对方带着防备应战。耽搁用原来的“受伤：闭关炼化减半 N 日”。
- **写回**：每个选项都给当事人写一条关于她的记忆（恩 / 救 / 助 / 怨 / 辱 / 夺……）并让他重想动机（rt=1）；看得见的事 55% 变成关于她的传闻（种类“她”），当事人圈子里的 3 个人跟着改看法、记一条“闻”。提醒、告状、拆台有机会被起念的人知道是谁（按其谨慎）。到期了结后会有“果”传闻。
- **少见的动作**：讨债只找真欠自己账的人；交易赊账门槛放宽；叛门动机门槛略降；示警会去提醒被盯上的熟人（也包括她）；劝和门槛 0.4；冲她偷窃的权重 ×1.3。

## 测试（tests/meddle_test.gd，已进 run_tests.sh）
- 8 种谋事 × 风声 / 插手 × 家 / 路 × 3 种情形 × 全部选项：404 次结算，无占位符、正文 ≤170 字；除“不插手”外都把她写进当事人记忆；插手后不能再插手、到日子照常了结。
- 8 局 × 100 日随机插手：谋事、走漏、风声在家 / 路上、各选项次数；与同一刻选“不管”的反事实对照，结局（事成 / 落空 / 被她了结、伤、破财、好感、门派）不同的比例 ≥0.5；打印例子。
- 少见动作都出现；节奏（16 局 × 50 日）在家 0.4–0.6、路上 0.2–0.42、最长连续 ≤3.2；带插手的局存读档一致；没有 plots 键的旧档照常跑。
