# 青庐 v0.13–v0.14 重设计：修仙的时间跨度 · 新开局 · 储物袋与法宝

> 性质：**设计草案**（2026-10-28，UTC+8）。实现分两版：**v0.13 = 时间按月 + 境界往后走 + 新开局 + 存档迁移**；**v0.14 = 储物袋 / 装备 / 物品生成**。每版发布时在 STATUS.md 写实际跑出的数字；这里的数字是目标值，没跑过的写“目标”。
> 玩家原话（2026-10-28 22:22）：“为啥一局是百来日？我想要修仙的那种跨度，一月一月的来，然后时间流逝几十年几百年那种”；“一开始的姑姑设定是啥啊，好奇怪不要这种奇怪设定”；“还有背包系统，装备系统等等，你找找开源的，一起设计了”。

## 0. 结论先说
1. **一回合 = 一个月**。一局从十六岁走到坐化或飞升，目标跨度 **一两百年到四五百年**（看她冲不冲得过金丹、元婴）。日历按“青庐 N 年 · 某月 · 某季”写，履历按年月记。
2. **境界不再停在筑基**：炼气九层 → 筑基（初/中/后）→ 金丹 → 元婴 → 化神 → 渡劫飞升。寿元按境界给年数：炼气 100、筑基 200、金丹 500、元婴 1000、化神 2000（与 NPC 同一张表）。筑基成功不再是结局，是一次“大事”，接着往下修。
3. **闭关以年计**：静室里可以“闭关一月 / 一年 / 十年 / 到破境”。长闭关时不问外事（江湖照常过，事件不找上门），出关时给一张“这些年江湖上的事”。
4. **NPC 一代代换人**：NPC 年纪按月长（以前按日长，一百日才长 0.28 岁）；道侣会生儿育女，孩子十六岁入仙途；收徒、宗门掌门坐化后有人继位；老一辈坐化，后辈接上。不认识的死人会被压缩，存档不会无限变大。
5. **姑母设定整个去掉**。新开局：她是青云宗外门落选的杂役弟子，领了遣散的灵石，托坊市的葛老三租下后山脚下一处没人要的旧洞府“青庐”，自己做散修。前任洞主留下两块阳田、一只旧丹炉和一本画满山路的《旧主手记》（原“姑母的路书”）。
6. **背包 / 装备**：数据结构借 **GLoot（MIT）** 的 prototree 思路并直接复用其 `Prototype` / `ProtoTree` 两个类（去掉 class_name，放 `scripts/vendor/gloot/`）；容量规则自写（储物袋按格）；词缀生成器自写（参考暗黑 II / 流放之路的“前缀 + 后缀 + 物品等级”）。物品是带履历的实例：谁炼的、谁用过、在哪丢的、被谁夺走。NPC 也带法宝，夺宝 / 交易 / 送礼 / 遗物会真的换手。

## 2. 时间：一回合一个月（v0.13）
| 项 | 旧（v0.12，回合=日） | 新（v0.13，回合=月） |
|---|---|---|
| 一回合 | 一日 | **一月**（存档里仍叫 `day`，含义改为“第几个月”，避免改几百处字段名；`s.tu = "month"` 标记） |
| 日历 | 正月初一… | **青庐 N 年 · X 月 · 春/夏/秋/冬**；节令按月（上元=正月、清明=三月、端午=五月、七夕=七月、中秋=八月、重阳=九月、冬至=冬月） |
| 她的年纪 | 无 | 十六岁开局；`age = 16 + 月/12`；人物卡、院子题头显示 |
| 寿元 | 120 日 | 按境界年数（下表）× 12 个月；显示为“寿元余 N 年” |
| 灵田 | 6 日一熟 | **6 个月一熟**（一年两季；冬季不长——冬月、腊月、正月三个月灵田不走进度，目标：一年约 1.5 熟） |
| 丹炉 | 聚气丹 2 日、筑基丹 6 日 | 2 个月、6 个月 |
| 赶路 / 路线节点 | 一日一段 | **一月一段**（路书一趟 6–10 个月） |
| 游历 | 一日一个小去处 | **一月一个小去处** |
| 干粮 | 一日一份 | 改名 **辟谷丹**，一月一颗（数值不变） |
| NPC 年纪 | 每回合 +1/360 岁 | **每回合 +1/12 岁** |
| NPC 修为 | 每回合 xp +0.6–1.4，升一级要 8×1.35^lv | 不改：折成月后，炼气→筑基约 28 年、→金丹约 70 年、→元婴约 170 年、→化神约 420 年，与寿元 100/200/500/1000 正好咬合 |
| 说书人冷却 / 最早出现 | 按日 | 数值不改，含义变成月（例：冷却 8 = 8 个月） |

### 2.1 境界与寿元（她与 NPC 共用）
| 境界 | lv | 寿元（年） | 她每月闭关得修为 | 小境界所需修为 | 目标用时（只闭关） |
|---|---|---|---|---|---|
| 炼气一–九层 | 0–8 | 100 | 10（+感悟炼化 ≤20） | 合计 600（v3.2 原数） | 3–5 年（含历练、炼丹）——炼气这段的 v3.2 经济与测试原样保留 |
| 筑基初 / 中 / 后 | 9–11 | 200 | 14 | 每段 2 000 | 每段约 10–12 年，筑基共约 35 年 |
| 金丹初 / 中 / 后 | 12–14 | 500 | 20 | 每段 6 000 | 每段约 25 年，金丹共约 75 年 |
| 元婴初 / 中 / 后 | 15–17 | 1000 | 28 | 每段 18 000 | 每段约 55 年，元婴共约 165 年 |
| 化神 | 18 | 2000 | 36 | 30 000（圆满后可渡劫） | 约 70 年 |
- 小境界（初→中→后）修为满了自动进。**大境界**（炼气→筑基、筑基后→金丹、金丹后→元婴、元婴后→化神）要回静室冲关：筑基照旧要筑基丹 + 心魔两问；之后三次大关要过心魔两问（从倾向题库抽），成功率 筑基后→金丹 55%、→元婴 45%、→化神 35%（v0.14 起丹药 / 法宝可加），失败：伤 12 个月、修为退 25%、寿元多扣 5 年，可再冲。
- 化神圆满可**渡劫**：成功率 40%，成 = 飞升结局；败 = 身死道消结局（或兵解，履历写明）。寿元尽 = 坐化结局。
- 合计目标：一位勤快的玩家约 20 岁筑基、55 岁前后结丹、130 岁前后元婴、300 岁前后化神、370 岁前后渡劫——**一局几百年**。
- 旧档里已经筑基结局的（ending = zhuji）：迁移后不再算“结局”，从筑基初期接着修（提示一句“筑基之后，路还长”）。

### 2.2 闭关
- 静室按钮：**一月 / 一年 / 十年 / 到破境**（另保留“炼完感悟为止”“到丹成”）。
- 一年以上算“长闭关”：江湖照常按月过（人物长岁、走动、破境、结仇、生子、坐化），但**事不找上门**；灵田、丹炉照常走。以下情况提前出关：修为满（该冲关了）、丹成（选了“到丹成”）、寿元余不到 5 年、受伤痊愈（选“到伤好”时）。
- 出关给一张“出关”卡：闭关多久、修为多少、这些年江湖上的大事（先列认识的人：破境、成亲、生子、坐化、继位），最多 6 条，其余进“江湖”页。

### 2.3 世代
- **生子**：结为道侣的两人都在世，每月约 0.25% 生一子（约 30 年一个）；孩子记进父母履历，十六年后入仙途（新人物，姓随父或母，带“父 / 母”关系，宗门随父母之一，认识她的父母 → 她也会听说）。
- **收徒**：筑基以上 NPC 每月 0.15% 收一个新人为徒（带“师 / 徒”关系）。
- **掌门**：每个宗门（散修除外）记一位掌门（该宗修为最高者）；掌门坐化 / 飞升 / 死，次月由宗内修为最高者继位，起一条传闻。
- **人口**：在世 NPC 上限 30 → 36；新人每月 4% 不变。
- **存档压缩**：死去超过 30 年、她不认识的 NPC，删掉记忆 / 关系 / 多余履历，只留名字、宗门、境界、生卒、最后 3 条履历。目标：一局 400 年后存档 < 1.5 MB（localStorage 上限约 5 MB）。

### 2.4 事件与引擎
- 引擎（`addons/storylet_engine`）不改：它只认 `se_now()` 返回的回合数；**一回合 = 一月**由青庐胶水（`scripts/saga.gd`）的 adapter 说明，内容包里的 `cooldown` / `delay` / `days` 一律读作“月”。
- 文案里写死的“三日”“半日”“第 N 日”逐条改成“三月”“半月”“某年某月”。
- 季节进事件文案（`jie()` 原来按日轮换节气，改按月取节气）。

## 3. 新开局：去掉姑母（v0.13）
**她是谁**：苏青禾（玩家可改名），十六岁，山下桃溪镇人。十三岁测出灵根（资质平平），进青云宗外门做了三年杂役弟子；今春外门大比落选，领了二十块灵石遣散。她托坊市卖杂货的**葛老三**作保，租下后山脚下一处荒了多年的旧洞府——**青庐**：两块阳田、一只旧丹炉、一间静室，还有前任洞主（一位早已坐化的老散修）留下的一本《旧主手记》，画满了后山、寒潭的山路。从此她是散修。
- 开局第一屏：葛老三把钥匙和手记递给她：“租钱一年一结。辟谷丹我按月给你补上——别饿死在山里，我收不着钱。”
- **心之所系**（原“最舍不得：姑母 / 小镇 / 旧书”）改为：**山门**（青云宗那级她没走完的台阶）/ 小镇 / 旧书。心魔第一问对应改写；旧档里选了“姑母”的迁成“山门”。
- 原姑母的功能分给：**葛老三**（每次回家把辟谷丹补到 8 颗——写成“按租约补给”；原“家书 +3”“姑母处寄存”取消，旧档寄存的那几颗并进仓里）；**旧主手记**（新手提示、路书支线）。院里的“姑母”热点换成“灶间 · 辟谷丹”。
- 所有文案（events / routes / xinmo / 江湖事件 / 内容包 / README / AGENTS 人物口吻）逐条改：家书 → 去掉或改成同门旧友来信；“姑母的路书” → 《旧主手记》；“背着姑母进山躲” → “护着镇上的老人进山躲”；“姑母欠的旧账” → “前任洞主欠的旧账”。
- 测试：全仓库（scripts / data / tests 期望 / README / AGENTS）`rg 姑母|姑姑|素娘` 为 0。

## 4. 存档迁移（v0.13：存档版本 2 → 3）
- 读入 v1 / v2 档自动迁成 v3，**不改旧档文件本身直到下次自动存档**；`qinglu_slot1`（v0.5 档）不碰；开新档前照旧把旧档归档到 `qinglu_prev`。
- 回合：旧档的 `day`（第几日）原样当作“第几月”——她已经经历的事一件不丢，日历从“第 N 日”变成“青庐 N/12 年”。（一百日的旧档 ≈ 八年多，合理。）
- 寿元：重算为 `(该境界寿元年数 × 12) − 年龄月数`，年龄 = 16 岁 + day 个月。旧档的“剩余日数”不再用；若旧档已因寿元耗尽坐化，结局保留。
- 结局：`ending = zhuji` 的档改成在世、筑基初期、修为 0，续上。
- `cherish = aunt` → `sect`；`aunt_ration` 并入辟谷丹（超过上限的进仓，存成灵谷）；`letter_pending` 删除。
- 江湖：`w.day` 同样当月；NPC 年纪不动（本来就是岁）；新加的掌门表、生育表首次读入时补建。
- 测试：v2 夹具档（第 40 日、炼气四层、带姑母寄存 2、江湖已开）→ v3 后可读、可继续玩 120 个月、再存再读一模一样；ending=zhuji 夹具 → 续修。

## 5. 储物袋与装备（v0.14）
### 5.1 物品数据
- **模板**（`data/items.json`，GLoot prototree 格式：`{"prototypes": {...}, "properties": {...}}`，子原型继承父属性）：
  - `法宝` → `飞剑`、`剑`、`伞`、`铃`、`印`；`法衣` → `道袍`、`软甲`；`佩饰` → `玉佩`、`戒`、`簪`；`功法` → `剑诀`、`吐纳`、`丹经`；`储物` → `布囊`、`储物袋`、`储物戒`、`芥子镯`；`丹药`、`符箓`、`灵材`（原有物品 id 并进来，可叠）。
- **实例**（存档里）：`{"u": 唯一号, "p": 原型 id, "g": 品阶, "n": 名字, "af": [[词缀 id, 数值], ...], "lv": 物品等级, "h": [[月, 事], ...], "o": 现持有者 id（0=她）}`；可叠的消耗品仍按 id 计数，不建实例。
- **品阶**：凡品 / 法器 / 灵器 / 宝器 / 仙器（颜色：墨灰 / 青 / 碧 / 绛 / 金）。物品等级 = 炼制者 / 掉落处境界；能用的最低境界：法器 炼气、灵器 筑基、宝器 金丹、仙器 元婴（越阶可持有，不能祭用）。
- **词缀**：凡品 0 条、法器 1、灵器 2、宝器 3、仙器 4；前缀改名字（“寒霜”“赤焰”“青锋”“流云”…），后缀写进说明（“·破甲”“·养魂”）。词缀表 ~40 条，字段 `id, name, pos(pre/suf), group, slots, stat, tiers[品阶]=[min,max], weight`。同 group 互斥。
- **履历**：生成时写“某年某月，万剑门孟雨霜于万剑门炼成”或“出自古战场”；易主时追加“某年被血煞门某某夺去”“某年她在坊市以 80 灵石购得”。人物卡、物品详情都能看到。

### 5.2 装备槽与效果
| 槽 | 放什么 | 作用（目标数值） |
|---|---|---|
| 法宝 | 剑 / 伞 / 铃 / 印 | 斗法力 + (品阶×10 + 词缀)：江湖里劫修、切磋、夺宝、拦路的胜负加成 |
| 法衣 | 道袍 / 软甲 | 受伤月数 −(品阶×8%，上限 40%)；词缀可加避瘴 / 避水 |
| 佩饰 ×2 | 玉佩 / 戒 / 簪 | 闭关修为 +%（玉佩）、感悟 +%（簪）、辟谷丹消耗减半（戒，某词缀）、寿元 +年（极稀有，“驻颜”） |
| 功法 | 玉简 | 闭关修为倍率（凡 ×1.0、法器 ×1.1 … 仙器 ×1.6）、炼化上限 +；一部功法要研读 N 个月才能换上（换功法有代价） |
| 储物 | 布囊 / 储物袋 / 储物戒 / 芥子镯 | 出门带的格数 6 / 12 / 20 / 32；每格可叠同物 10 |
- 她与 NPC 用同一套：NPC 生成时按境界配 0–3 件（筑基必有法宝），斗法力进 agency 的胜负计算。

### 5.3 物品与人
- **夺宝**（agency 已有）：赢的一方从输的那里拿走最值钱的一件（履历记一笔）；她被夺 → 物品真的没了，夺的人身上能看到。
- **交易**（相逢已有“交易”）：对方报价 = 价值 ×（贪 +30% / 善 −20% / 好感修正）；她可以卖。
- **送礼**：好感 ≥ 阈值、或报恩动机，NPC 送她一件；她可以把东西送给 NPC（好感 + 价值/10，按对方喜好 `likes` 加倍）。
- **遗物**：NPC 死，东西给道侣 / 徒弟 / 子女；没人接的留在死处，日后在那处游历可能捡到（“一柄锈了的剑，剑格上刻着某某”）。
- **事件引擎**：saga adapter 新增 op：`give_item {to, proto|grade|from}`、`take_item {from, to, best}`、`gen_item {grade, slot, place}`；条件函数 `has_gear(a, slot)`、`gear_power(a)`。内容包用这些写“为一柄剑结的仇”。
- **经济**：价值 = 品阶基价（凡 5 / 法器 40 / 灵器 300 / 宝器 2 500 / 仙器 20 000 灵石）×（1 + 0.15×词缀数）；坊市只卖凡品、法器（每年换货）；灵器以上只从人、秘境、古战场来。灵石来源（现有：灵田卖青芝、事件）在 v0.14 加“坊市寄卖”。

- **储物袋页**（院子“仓”与出门“行囊”合成一页，上方分页：随身 / 洞府）：4 列格子（360 宽时每格 78px，390 宽 84px），格里是物品小图 + 品阶色边 + 右下数量；点格子弹底部抽屉：大图、名字（品阶色）、词缀、履历、按钮（装上 / 卸下 / 带走 / 放回 / 送人 / 丢弃）。
