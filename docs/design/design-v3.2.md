## 1. 一段话介绍与核心循环

她本是清溪镇药铺掌柜家的养女，十六岁得了一张残缺的引气诀，镇外一间废弃药庐也归了她。玩家陪她从这间漏雨的青庐出发，一程一程往外走，后山、寒潭、渡口、山村，再到剑派、古城，最后到天门之下。路上遇到的人会记得她做过什么，地方会因为她来过而变样。每次出门，她靠家里种出、炼出的东西撑着；每次回来，带回的种子、方子、人情和心得又让青庐长出新的样子。最后她渡劫、飞升，柳闻莺把这一路写成《青庐行记》。

```
青庐（在家操作 0 日）：收获 · 排丹炉 · 服丹 · 定灵脉 · 收拾行囊
      │ 看风闻 → 带什么、走哪条
      ▼
历练（推进游戏日）：路线图选路 → 事件卡抉择（代价写在按钮上）
      │ 带回：药材、种子、方子、人情、感悟、路书，以及地点的变化
      ▼
回家：结算 → 闭关（炼化感悟，田和炉在后台继续）→ 世事变化 → 再出门
      ▼
突破：家里炼的丹 + 路上攒的感悟 + 心魔劫（题目来自她做过的选择）
```

## 2. 时间与结算规则（v3 写死）

### 2.1 游戏日

| 规则 | 内容 |
|---|---|
| 单位 | 只有整数“日”，没有半日。 |
| 什么会推进日子 | 只有两件事：历练中走节点，在家闭关。冲关也耗 1 日。 |
| 在家操作 | 收获、排丹炉、服丹、定灵脉、收拾行囊，都是 0 日。 |
| 后台进度 | 田、水田、丹炉都按游戏日推进，不管她在家还是在路上。 |
| 不随真实时间流动 | 没有离线收益，也没有挂机等待。 |

### 2.2 节点耗时与返程

| 情形 | 耗时 |
|---|---|
| 普通节点 | 1 日 |
| 选项附加 | 选项按钮上明写，比如“+2 日”“陪坐 3 日” |
| 细采 | +1 日 |
| 走到终点 | 每张路线图最后一层是“归途”节点。走完归途就到家，**不再收返程** |
| 半路折返 | 耗 ⌈已走日数 ÷ 2⌉ 日，每日照扣干粮；回程不触发事件，路书照常记录 |
| 干粮吃完 | 每日扣 1 寿元，并进入“饥乏”（对峙成功率 −20%）；不会直接失败，也可以随时折返 |

### 2.3 同日结算顺序（每过一日，按顺序执行）

1. **日初生产**：每块田的生长 +1；丹炉队列只推进队首一项 +1；水田 +1。
2. **收获入库**：作物熟了自动入仓，基础青芝自动续种；丹药炼成后放进“待取”。筑基丹在这一步判定成功与否。
3. **当日消耗**：在路上扣 1 日干粮（不够就进入饥乏）。闭关则修为 +10，再炼化待炼化感悟，最多 20 点。
4. **世事检查**：倒计时类的世事到期就生效，比如山村迁走。
5. **玩家操作**：在家的一切操作都是 0 日。
6. **新队列生效**：第 5 步里新排的丹，从下一个日初开始计时。也就是说，第 D 日排下一颗需要 k 日的丹，会在第 D+k 日的第 2 步出炉。

|---|---|
| 容量 | 炼气 12 日份（筑基 20，金丹 30） |
| 姑母补给 | 每次回家，不足 8 日份就免费补到 8；已有 8 日份或以上就不补 |

### 2.6 修为上限、余韵与冲关

- **待炼化感悟软上限 140**：待炼化超过 140 后，路上新得的感悟只计一半（向下取整），界面显示“思绪繁杂”，回家闭关把它压回 140 以下就恢复。
- 炼气圆满时修为封顶 **600**。多出的修为（不管来自闭关、炼化还是丹药）都存进“圆满余韵”，上限 120，筑基后作为起始修为。
- **冲关条件**：人在青庐静室；修为 600；手上有筑基丹。耗 1 日。可以随时推迟，没有时间窗限制。
- 修为满了还在闭关时，闭关预设会显示“修为已满，继续闭关只会攒余韵（剩 X 点到上限）”。
- 模拟器专门统计“修为满后还在等丹的闭关日”，验收标准是均衡路线为 0（见 11.3）。

### 2.7 寿元与“坐化于青庐”

- 寿元按游戏日扣除，饥乏的日子再多扣 1。**v3.2：炼气寿元 120 日。**灰盒 20 组路线用掉 31–41%，正常打法在各境界只用掉 30–50%；只有比均衡路线慢 3 倍以上才会坐化。
- **余寿为 0**：触发结局 **“坐化于青庐”**。她回到青庐静室坐化，屏幕上依次翻过《青庐行记》的每一页；玩家选择传承人（姑母、阿蛮、周砚、封存），存档标记为“已完结”，不会删除。这是一种正式结局，不是 Game Over。

## 4. 历练设计

### 4.1 一次历练

1. 定目的地：目标卡、委托或风闻。
2. 出发页：路线图缩略、1–2 条风闻、三段式行囊（干粮袋 / 随身 6 格 / 采药篓 30 件）。
3. 逐个节点推进，每个节点一张事件卡。
4. 走到“归途”就回家；半路折返按 2.2 计算。
5. 回家时出“这一趟”小结：带回的东西、认识的人、变了样的地方、新解锁的路线或节点。

**不会卡死**：每个险地都至少有一个不需要钥匙的选项（绕路或硬闯），代价写明。

### 4.2 节点类型

| 节点 | 作用 |
|---|---|
| 野地 | 采集，可以细采（+1 日）；从轻文本池抽描写 |
| 人家 | 交易、风闻、委托；NPC 有记忆 |
| 险地 | 用钥匙过 / 绕路 / 硬闯 |
| 机缘 | 一次性事件，有多种取法 |
| 对峙 | 选应对方式，胜率写在选项上 |
| 歇脚 | 吐纳、写家书、整理行囊 |
| 异象 | 线索，几条拼起来能揭开隐藏地点 |
| 归途 | 路线图最后一层；走到即回家，不收返程 |

### 4.3 三层后果（沿用 v2，加两条规则）

| 层 | 时间窗 | 要求 |
|---|---|---|
| 当场 | 选完立刻 | 一定有可见变化：物品、路线、关系标记、信息，至少一样 |
| 近期 | 本趟剩下的节点，或下次回家 | 关键选择都要有，而且必须**改变后续的节点或选项**，不能只给数值 |
| 远期 | 后续境界 | 只给值得的选择；**切片结束前至少回响一次**（结尾变体、心魔题、或者回家时的口信） |

### 4.4 反等价补偿规则（v3 新增，写作和评审时逐条核对）

1. 选项的代价和当场回报**不能是同一种资源、差不多的数量**。比如“绕路 +2 日，当场送 2 日干粮”这种设计禁止出现。
2. 关键选择的近期后果必须是**形态变化**：开一条路或关一条路、改变某个节点、多一个人或少一个人、改变主药的来源。不能只是“省 1 日”或“多几个灵石”。
3. 每个关键选择至少要有一个选项，它的损失在切片内**补不回来**。

### 5.4 为什么不能“全部点满”

灵脉 5 点只够开 4 样设施再加 1 样；丹炉只有一条队列；有世事倒计时；寿元有限；稀有种子是一次性的。

### 5.5 每次回家，至少有一处看得见的变化

田里的图标在苗、茂盛、可收三态之间切换；丹炉在冷、有火、丹成之间切换；姑母留下的口信；新入住的人；路书上多出来的标记。这些都由真实状态驱动，不是装饰。

## 6. 心魔劫（覆盖与保底）

### 6.1 结构

切片的心魔劫共 3 幕，每幕一道题。答案不分对错，只看和她做过的事是否一致。

| 幕 | 题源 | 保证 |
|---|---|---|
| 第一幕 | 捏人时选的“最舍不得”（姑母 / 小镇 / 一本书） | 一定有题 |
| 第二、三幕 | 三个关键选择，按优先级：老龟 → 夜渡 → 枯田，取前两个遇到过的 | 每个关键选择的每个选项都有对应的题：3 × 4 = 12 道 |
| 保底 | 关键选择不够两个时（比如夜渡选 D、山村已迁走），从倾向标签题池里补 | 标签由全部选择累计：“力”（硬闯过）、“利”（收过钱）、“善”（帮过人）、“避”（绕过路）。每个标签 1 道题，再加 1 道通用题“为何离家”，总共 5 道。因为任何打法都至少会落到一个标签上，题池不会空 |

### 6.2 校验器（实现时必须先有）

遍历所有关键选择的选项组合，检查每种组合都能抽出 3 道不重复的题，而且题目引用的事真的发生过。覆盖率必须 100%，否则不能合入。

### 6.3 失败

- 回答和过往记录对不上，而且之后没有补救标记（比如夜渡 A 之后又在别处帮过孩子），这一幕就没过。
- **代价**：筑基丹**保留**；进入“心境不稳”，必须先闭关 3 日（炼化减半）才能再冲关；写进《青庐行记》。
- 模拟器的“心魔失败”分支：**第 42 日**筑基，比均衡路线晚 4 日（11.4）。

### 6.4 灰盒期

只做两道：第一幕的保底题，加老龟的 4 道选项题（作为第二幕）。

### 11.5 仍未解决的问题（不阻塞灰盒，但不能当成已经修好）

1. **偏历练的代价仍然太轻。** 软上限 140 只折损 19 点感悟，偏历练依旧只比均衡慢 2 日。原因是感悟在最后一次闭关里就能补回来，玩法上没有“中途必须回家消化”的压力。灰盒期观察玩家是否感受到“待炼化”的压力。两个候选改法都**还没模拟**：①心魔劫的题和待炼化挂钩，冲关时待炼化 >0 就多一幕“杂念”题；②待炼化超过上限时，对峙成功率下降。
2. **水田 + 老龟 B 的闭关占比 64–65%，超过 60%。** 原因是莲子种下后，水田就不再产灵谷，也就没有那 1 株青芝。候选改法（未模拟）：种莲子期间，莲叶也算一份“灵谷”，每 6 日照样给 1 株青芝。
3. 灰盒路线的最后一次闭关长达 15 日（第 21 → 36 日），因为灰盒内容少、感悟少，修为主要靠闭关基础补。界面上只是一次点击，但玩家会不会觉得“空”，要在灰盒试玩时记录。
4. 模拟器不覆盖阅读速度波动、对峙胜率、随机掉落和心魔劫里的选择，这些只能靠试玩。
