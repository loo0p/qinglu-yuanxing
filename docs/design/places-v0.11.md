# v0.11 地点与游历（places）

> 用户反馈：“剧情还是定制化成分比较高，应该随着剧情推进逐渐解锁地点，然后在一个地点里游历可以遇到各种各样的人。”

## 目标
- 世界不是两条写死的路线，而是一张**逐步认得**的图：12 处地方，开局只认得 2 处，60–120 日里陆续摸清。
- 去一处地方是**游历**：一日去一个小去处（采药 / 换灵石 / 静坐 / 听风声），也看看今天这一带有谁。
- 碰见谁 = 此刻**真在这里的人**（人物按自己的念头走动）+ 偶尔的过路生面孔。可以上前：攀谈、打听风声、交易、切磋、结伴。
- 原来的后山 / 寒潭路线（葛老三、老龟、赤阳果……）不删，成了这两处的**支线路书**。
- 江湖事件（人物自主、插手、风声……）照旧在哪儿都可能找上门；地点只调权重，不圈死。

## 地点（scripts/travel.gd · PL / UNL）
| 地方 | 离青庐 | 小去处 | 怎么认得（哪条先到算哪条） |
|---|---|---|---|
| 后山、坊市 | 1 日 | 山涧/松林/断崖；茶肆/拍卖行/巷尾 | 开局就认得 |
| 寒潭 | 2 | 潭边石滩/雾林/瀑下 | 炼气二层；或风声 2 条；或去过（旧档 hantan_visited） |
| 药王谷、青云宗、云梦泽 | 2/2/3 | … | 炼气四层；或二层起风声 3 条；或熟人引路（青云宗另：经历过宗门招徒/入门试炼） |
| 玄霜谷、落霞宫、万剑门 | 3 | … | 炼气五层；或三层起风声 3 条；或熟人引路 |
| 古战场 | 3 | … | 炼气六层；或四层起风声 4 条；或熟人引路 |
| 秘境 | 3 | … | 炼气七层；或四层起风声 4 条；或经历过“秘境/秘境请柬” |
| 血煞门 | 4 | … | 炼气八层；或五层起风声 5 条；或熟人引路 |

- **风声**：江湖传闻（world.rumor）里提到某个还没认得的地方，就记一笔；在茶肆、医棚、渔村这类“news”去处听闲话，也有六成机会听到一处。
- **引路**：认识的人（好感 ≥12 或有交情）本门或眼下所在的地方她还不认得 → 每日 10% 起意，排进人物自主的找上门队列（权重 ×0.4，不挤掉要紧事），16 日过期。答应就认得了，还加好感。
- **插手**：插手一件谋着的事，事发地还不认得时也就认得了（“不管”不算）。
- 解锁时弹一行提示、记进行记与生平（chron）。

## 人物在哪（TV.daily / dest / move）
- 每人 `place`；每日 12% 动身（重伤的不动），75% 去“念头想去的地方”，否则随便走走。
- 念头 → 去处：找人（复仇/报恩/求偶/护人/压人…）跟着对方；求财、交游 → 坊市或野地；探秘 → 野地；疗伤 → 药王谷；叛门 → 离开本门；扬名 → 万剑门/青云宗；其余回本门。
- 测：每人每日挪动约 0.08 次；“追着人”的念头有 52% 与对象同处；没有哪处挤着超过 45% 的人。

## 游历一日（game_state.roam_spot → TV.roam_day）
1. 耗 1 日、1 份干粮（tick road，江湖照常走一日，路上的事照常会来）。
2. 按去处出产：herb 65% 采到青芝（远处多一些，15% 是续骨草）；ls 60% 得灵石；wu 感悟 +2~4；news 60% 听到一处没去过的地方。
3. 这天没别的事缠着时，72% 碰上人（昨天有事则 35%，连着两天有事就歇一天）→ 事件“相逢”。挑谁：在此的人为主（熟人、念头合这个去处的权重高，3 日内刚见过的降权），25% 是过路的生面孔（人少时新生一位当地门派的人，否则把一位不认识的人挪过来）。
4. 也可以主动“上前”：游历页列出这一带的人（熟人 ≤3 + 生面孔 ≤2），每日只能主动搭一次话。

## 相逢的选项（TV.present / resolve）
- 上前攀谈：认识、加好感；对方会说起近来的念头（想报仇、想破境……），也可能透出 TA 正谋着的事（之后能插手）。
- 打听风声：先问谋着的事 → 再问还没认得的地方（风声 +2）→ 再问近来的传闻。
- 交易（4 灵石换一件人物自主的货）、切磋（看修为与运气，赢了感悟多些，傲气/想压人的输家会记恨）、结伴走一程（好感 +6、感悟 +2）、点个头走开。

## 界面（scripts/main.gd）
- 「历练」页 = 世界图（web_portrait/bg/map_world.webp，生成的水墨地图）。认得的地方是可点的纸签（地名 / 几日 / 熟人数），只听过风声的是淡淡的“某某？”。点开是底部抽屉：说明、离家几日、小去处、熟人在那边、干粮、**去游历**；后山/寒潭多一个“出发：后山（姑母的路书）”。
- 游历页：地名 + 游历几日；三个小去处按钮；“这一带的人”（看看 / 上前）；最近两行游历记；回青庐（N 日）/ 去别处 / 坊市买干粮 / 走姑母的路书。
- 回家结算沿用“回到青庐”（多一行“在某地一带游历了 N 日”）。

## 测试（tests/travel_test.gd，已进 run_tests.sh）
16 局 × 100 日（闭关—游历—回家循环）：解锁进度、解锁理由 ≥4 种、每处都在某局解锁过；在家约 0.5 件/日、游历日 0.45–0.95、最长连着有事 ≤4；相逢的人都在当地；每处都发生过事件；引路出现过；人物走动统计；游历途中存读档后往后完全一致；旧档迁移；每个相逢选项都有结果、无占位符、正文 ≤170 字。UI 冒烟加了“世界图 → 坊市 → 游历 → 上前相逢 → 去别处 → 回青庐”。
